## 1. Вхід та інтерфейс адмін-панелі

### Як увійти


| Що потрібно        | Деталі                                                 |
| ------------------ | ------------------------------------------------------ |
| **Адреса**         | `https://ваш-домен/oyra-panel/`                        |
| **Сторінка входу** | `https://ваш-домен/oyra-panel/login/`                  |
| **Логін**          | Email або ім'я користувача, видане адміністратором     |
| **Пароль**         | Особистий пароль облікового запису з правами персоналу |


> **Примітка.** Адреса `/admin/` на цьому сайті **не працює**. Використовуйте лише `/oyra-panel/`.

Після успішного входу ви потрапляєте на головний екран з назвою **«Oyra — Панель адміністрування»**.

### Огляд інтерфейсу

Панель побудована на сучасному інтерфейсі з **боковим меню зліва** та **робочою зоною справа**.

**Бокове меню** містить такі групи розділів:


| Група                 | Що всередині                                                                                   |
| --------------------- | ---------------------------------------------------------------------------------------------- |
| **Налаштування**      | Сайт, Соцмережі                                                                                |
| **Вміст сторінок**    | Тексти та банери головної, меню, підвал, реквізити                                             |
| **Каталог**           | Товари, Топ продажу, Новинки, Топ переглядів, Категорії, Бренди, Постачальники, Характеристики |
| **Керування акціями** | Товари на акції, Промокоди                                                                     |
| **Продажі**           | Замовлення                                                                                     |
| **Клієнти**           | Користувачі, Обране, Підписки, Дропшипінг                                                      |
| **Контент**           | Блог, Інфо-сторінки, FAQ                                                                       |
| **Модерація**         | Відгуки                                                                                        |


**Корисні елементи інтерфейсу:**

- **Пошук у меню** — поле пошуку у верхній частині бокової панелі допомагає швидко знайти потрібний розділ.
- **Таблиці (списки)** — у кожному розділі відображаються записи у вигляді таблиці з колонками та кнопками дій.
- **Фільтри** — праворуч або зверху таблиці можна звузити список за категорією, статусом тощо.
- **Пошук у таблиці** — поле «Пошук» над таблицею шукає за назвою, артикулом, email тощо (залежить від розділу).
- **Кнопки дій** — «Додати», «Зберегти», «Зберегти і продовжити редагування», «Видалити».

> **Важливо.** Не закривайте вкладку під час завантаження великих файлів (імпорт, багато фото) — дочекайтеся повідомлення про результат.

## 2. Керування товарами (Каталог)

Перейдіть: **Каталог → Товари**.

### 2.1. Створення нового товару (покроково)

1. Натисніть **«Додати товар»** (або **«+ Додати»**) у правому верхньому куті.
2. Заповніть поля у блоках форми.
3. Натисніть **«Зберегти»** або **«Зберегти і додати інший»**.



#### Обов'язкові поля


| Поле           | Опис                                                                                |
| -------------- | ----------------------------------------------------------------------------------- |
| **Назва**      | Назва товару, яку бачить покупець                                                   |
| **Слаг (URL)** | Частина адреси сторінки товару. Заповнюється **автоматично** з назви після введення |
| **Артикул**    | Унікальний код товару (SKU). Не може повторюватися                                  |
| **Категорія**  | Розділ каталогу, до якого належить товар                                            |
| **Ціна**       | Актуальна ціна в гривнях                                                            |




#### Основні поля (блок «Основне»)


| Поле              | Як заповнювати                                                      |
| ----------------- | ------------------------------------------------------------------- |
| **Назва**         | Коротка, зрозуміла назва. Наприклад: «Кросівки Nike Air Max 90»     |
| **Слаг (URL)**    | Зазвичай не потрібно змінювати — формується з назви латиницею       |
| **Артикул**       | Код від постачальника або внутрішній код. Наприклад: `SKU-12345`    |
| **Категорія**     | Оберіть зі списку. Почніть вводити назву — з'явиться підказка       |
| **Бренд**         | Необов'язково. Оберіть бренд, якщо він є в каталозі                 |
| **Постачальник**  | Необов'язково. Хто постачає цей товар (корисно для імпорту прайсів) |
| **Короткий опис** | 1–2 речення для картки товару в каталозі                            |
| **Опис**          | Повний опис з форматуванням (жирний текст, списки тощо)             |




#### Ціни та наявність (блок «Ціни та наявність»)


| Поле           | Як заповнювати                                                                                                                         |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| **Ціна**       | Поточна ціна продажу                                                                                                                   |
| **Стара ціна** | Попередня ціна — показується перекресленою, якщо товар на знижці                                                                       |
| **Залишок**    | Кількість одиниць на складі (ціле число)                                                                                               |
| **Наявність**  | Статус для покупця: «Є в наявності», «Немає в наявності», «Очікується». **Автоматично оновлюється** при збереженні залежно від залишку |
| **Акція до**   | Дата й час, до якої діє акційна ціна (необов'язково)                                                                                   |




#### Мітки (блок «Мітки»)


| Поле                 | Що робить                                                                                               |
| -------------------- | ------------------------------------------------------------------------------------------------------- |
| **Активний**         | Увімкнено — товар може з'явитися на сайті (якщо категорія теж активна). Вимкнено — товар **прихований** |
| **Хіт продажу**      | Показує мітку «Хіт» і додає до секції «Топ продажу»                                                     |
| **Новинка**          | Показує мітку «Новинка»                                                                                 |
| **Акція**            | Показує мітку «Акція»                                                                                   |
| **Передоплата 100%** | Покупець може оплатити лише повністю                                                                    |
| **Порядок**          | Чим більше число — тим вище товар у списках з сортуванням за порядком                                   |


> **Важливо.** Товар з'явиться на сайті лише якщо **увімкнено «Активний»** і **категорія теж активна**. Неактивна категорія ховає всі товари в ній.



#### Прив'язка до категорії та бренду

- **Категорія** — обов'язкове поле. Без категорії зберегти товар неможливо.
- **Бренд** — необов'язкове. Якщо потрібного бренду немає, спочатку створіть його: **Каталог → Бренди → Додати бренд**.

### 2.2. Робота з медіа (фото товару)

Фото знаходяться у двох місцях форми товару.

#### Швидке завантаження — поле «Додати фото»

У блоці **«Фото»**:

1. Натисніть **«Додати фото»** (або «Вибрати файли»).
2. Можна обрати **одне або кілька зображень одразу**.
3. Збережіть товар — фото потраплять у галерею.



#### Галерея фото (нижче форми)

Після збереження товару з'являється таблиця **«Галерея фото»**:


| Колонка        | Призначення                                                          |
| -------------- | -------------------------------------------------------------------- |
| **Зображення** | Завантажити або замінити файл                                        |
| **Превʼю**     | Мініатюра з підказкою щодо розміру                                   |
| **Alt-текст**  | Опис зображення для пошукових систем (необов'язково)                 |
| **Головне**    | Позначте одне фото як головне — воно показується на картці товару    |
| **Порядок**    | Перетягніть рядки (**drag-and-drop**), щоб змінити порядок у галереї |


Якщо головне фото не обрано — першим у списку вважається головним.

#### Рекомендації щодо зображень


| Параметр                      | Значення                                                               |
| ----------------------------- | ---------------------------------------------------------------------- |
| **Формати**                   | JPG, PNG або WebP                                                      |
| **Рекомендований розмір**     | 800×800 пікселів (квадрат)                                             |
| **Максимальний розмір файлу** | 2 МБ                                                                   |
| **Обробка**                   | Файли автоматично конвертуються у WebP для швидшого завантаження сайту |


> **Порада.** Використовуйте однаковий стиль фото (фон, освітлення) для всіх товарів однієї категорії — каталог виглядатиме охайніше.



#### Відео (блок «Медіа»)


| Поле          | Опис                                    |
| ------------- | --------------------------------------- |
| **YouTube**   | Посилання на відео YouTube              |
| **Відео URL** | Посилання на відеофайл                  |
| **Є відео**   | Позначка, що на сторінці товару є відео |

У таблиці **«Характеристики»** (під галереєю) додайте параметри товару:


| Поле             | Приклад                                                                  |
| ---------------- | ------------------------------------------------------------------------ |
| **Група**        | «Загальні», «Розміри» (групи створюються в **Каталог → Характеристики**) |
| **Назва**        | «Колір», «Матеріал»                                                      |
| **Значення**     | «Чорний», «Шкіра»                                                        |
| **Порядок**      | Порядок показу                                                           |
| **У порівнянні** | Чи показувати в блоці порівняння товарів на сайті                        |

### 2.4. Редагування та пошук товарів



#### Як знайти потрібний товар

1. **Каталог → Товари**.
2. Використайте **поле пошуку** — шукає за **назвою** та **артикулом**.
3. Застосуйте **фільтри** (праворуч):
  - Активний / неактивний
  - Наявність
  - Категорія
  - Бренд
  - Постачальник
  - Хіт продажу, Новинка, Акція
4. Натисніть на **назву товару** або **фото**, щоб відкрити картку редагування.



#### Швидке редагування прямо в таблиці

У списку товарів можна змінити без відкриття картки:

- **Ціна** — поле вводу в колонці «Ціна» (зміни зберігаються автоматично).
- **Наявність** — випадаючий список у колонці «Наявність».

Поруч з полем з'явиться статус збереження.

#### Як приховати товар без видалення

1. Відкрийte картку товару.
2. Розгорніть блок **«Мітки»**.
3. **Зніміть позначку «Активний»**.
4. Натисніть **«Зберегти»**.

Товар залишиться в базі, але **не відображатиметься на сайті**. Щоб повернути — знову увімкніть «Активний».

> **Альтернатива.** Встановіть **Залишок = 0** — наявність стане «Немає в наявності», але товар може лишатися видимим у каталозі (залежить від фільтрів сайту).



#### Видалення товару

1. Відкрийте картку товару.
2. Натисніть **«Видалити»** (зазвичай зліва внизу, червона кнопка).
3. Підтвердіть дію.

> **Важливо.** Видалення **незворотне**. Якщо товар може знадобитися пізніше — краще зніміть «Активний».

## 3. Імпорт та масове оновлення даних

Імпорт дозволяє завантажити або оновити сотні товарів з файлу постачальника (прайс, вигрузка Prom/Siker).

### 3.1. Де знаходиться імпорт

1. Перейдіть: **Каталог → Постачальники**.
2. Відкрийте картку потрібного постачальника (натисніть на назву).
3. У правому верхньому куті натисніть **«Імпорт файлу»**.

Або перейдіть за адресою:  
`/oyra-panel/catalog/supplier/<номер-постачальника>/import/`

> Якщо постачальника ще немає — створіть його: **Каталог → Постачальники → Додати постачальника** (достатньо вказати **Назву**).

---



### 3.2. Вимоги до файлу



#### Підтримувані формати


| Формат    | Примітка                                                    |
| --------- | ----------------------------------------------------------- |
| **.xlsx** | Вигрузка Excel (Prom, Siker тощо) — найпоширеніший варіант  |
| **.csv**  | Таблиця з розділювачем (кома, крапка з комою або табуляція) |
| **.json** | Структурований файл (для технічних вигрузок)                |




#### Обов'язкова колонка

У **першому рядку** файлу (заголовки) обов'язково має бути колонка з **артикулом**:


| Прийняті назви колонки                        |
| --------------------------------------------- |
| `Код_товара`, `sku`, `артикул`, `vendor_code` |


Регістр літер не має значення.

#### Рекомендовані колонки


| Дані          | Приклади назв колонок (укр. / рос.)                                        |
| ------------- | -------------------------------------------------------------------------- |
| **Назва**     | `Название_позиции_укр`, `name_uk`, `назва` / `Название_позиции`, `name_ru` |
| **Ціна**      | `Цена`, `price`, `ціна`                                                    |
| **Залишок**   | `Наличие`, `stock`, `залишок`, `qty`                                       |
| **Категорія** | `Название_группы`, `category`, `категорія`                                 |
| **Опис**      | `Описание_укр`, `description_uk` / `Описание`, `description`               |
| **Фото**      | `Ссылка_изображения`, `images`, `image`, `фото`, `picture`                 |

> **Фото товару.** Якщо в колонці `Ссылка_изображения` кілька посилань — розділяйте їх комою (стандарт вигрузки Prom/Siker). Система сама завантажить ці фото в галерею товару, **але тільки якщо в товару ще немає жодного фото**. Якщо галерея вже заповнена (вручну або з попереднього імпорту) — вона не змінюється, щоб уникнути дублікатів.




#### Приклад структури файлу (.xlsx / .csv)


| Код_товара | Название_позиции_укр | Цена | Наличие | Название_группы | Ссылка_изображения                              |
| ---------- | -------------------- | ---- | ------- | --------------- | ------------------------------------------------ |
| 1001       | Кросівки білі        | 2499 | 10      | Взуття          | https://cdn.example.com/1001-1.jpg               |
| 1002       | Футболка блакитна    | 599  | 0       | Одяг            | https://cdn.example.com/1002-1.jpg, https://cdn.example.com/1002-2.jpg |


---



### 3.3. Покроковий процес імпорту

1. **Каталог → Постачальники** → оберіть постачальника → **«Імпорт файлу»**.
2. У полі **«Файл постачальника»** оберіть файл (.xlsx, .csv або .json).
3. У полі **«Мова назви та опису»** оберіть:
  - **Українська** — якщо у файлі колонки з `_укр` або українські назви (зазвичай це правильний вибір).
  - **Російська** — якщо потрібно взяти колонки `Название_позиции`, `Описание` тощо.
4. Натисніть **«Завантажити та імпортувати»**.
5. **Не закривайте сторінку** — для великих файлів (сотні товарів) обробка може тривати кілька хвилин, особливо якщо система довантажує фото за посиланнями. З'явиться індикатор «Триває імпорт файлу…».
6. Після завершення перегляньте блок **«Результат імпорту»**.



#### Що означає результат


| Показник                             | Значення                                                           |
| ------------------------------------ | ------------------------------------------------------------------ |
| **Створено**                         | Нові товари, яких раніше не було в каталозі                        |
| **Оновлено**                         | Існуючі товари з тим самим артикулом — оновлені ціни, залишки тощо |
| **Пропущено**                        | Рядки, які не вдалося зберегти                                     |
| **Помилок**                          | Кількість рядків з помилками                                       |
| **Потрібно розкласти по категоріях** | Нові товари без відповідної категорії в каталозі                   |
| **Завантажено фото**                 | Скільки фото довантажено за посиланнями з файлу                    |
| **Не вдалося завантажити фото**      | Посилання з файлу було недоступне — додайте фото вручну            |




#### Правила оновлення

- **Новий товар** (артикул не знайдено): потрібні **артикул + назва + ціна**. Залишок за замовчуванням — 0.
- **Існуючий товар** (артикул уже є): оновлюються лише **заповнені** поля. Порожні комірки **не стирають** старі дані.
- **Категорія** підставляється автоматично за назвою з файлу. Якщо збігу немає — новий товар потрапляє в службову категорію **«Імпорт / Без категорії»** і **не видно на сайті**.

> **Після імпорту.** Якщо є товари в «Імпорт / Без категорії»: **Каталог → Товари** → фільтр за категорією **«Імпорт / Без категорії»** → відкрийте кожен товар і оберіть правильну **Категорію**.

---



### 3.4. Типові помилки імпорту та як їх виправити

Після імпорту таблиця **«Що пішло не так і як виправити»** показує до 50 помилок.


| Проблема                            | Як виправити                                                                                                             |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| **Не знайдено колонку з артикулом** | Перевірте перший рядок файлу — має бути колонка `Код_товара`, `sku` або `артикул`                                        |
| **У файлі немає рядків з товарами** | Файл містить лише заголовки або порожній — завантажте повну вигрузку                                                     |
| **У рядку немає артикула**          | Заповніть код товару або видаліть порожній рядок                                                                         |
| **Дублікат артикула в файлі**       | Залиште один рядок з цим кодом, інші видаліть                                                                            |
| **Новий товар без назви**           | Заповніть колонку назви або змініть **«Мова назви та опису»**                                                            |
| **Ціна має бути числом**            | У колонці «Цена» лише числа: `1999` або `1999.50` (без тексту чи символів валюти)                                        |
| **Залишок має бути цілим числом**   | У колонці «Наличие» — цілі числа: `0`, `1`, `10`                                                                         |
| **Некоректний формат файлу**        | Збережіть як `.xlsx`, `.csv` або `.json`                                                                                 |
| **Не вдалося декодувати CSV**       | Збережіть CSV у кодуванні UTF-8 (у Excel: «Зберегти як → CSV UTF-8»)                                                     |
| **Конфлікт даних при збереженні**   | Перевірте, чи немає іншого товару з таким артикулом. Якщо помилка повторюється — зверніться до технічного адміністратора |
| **Товар без фото після імпорту**    | Перевірте назву колонки — має бути `Ссылка_изображения` (або `images`/`фото`); перевірте, що посилання відкривається у браузері; якщо в товару вже є фото — новий імпорт його не замінює |


> **Порада.** Виправте помилкові рядки у файлі та імпортуйте знову. Успішно імпортовані рядки просто оновляться повторно — це безпечно.

- **Позиції** — список товарів (назва, артикул, ціна, кількість).
